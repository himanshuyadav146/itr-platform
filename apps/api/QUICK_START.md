# 🚀 Quick Start Guide

## 3-Step Setup

### 1. Start Services
- Open XAMPP/MAMP
- Start **Apache** and **MySQL**

### 2. Setup Database
Visit in browser: **http://localhost/api/setup.php**
- Enter MySQL credentials (default: root, empty password)
- Click "Setup Database"
- ✅ Done!

### 3. Test API
- Import `ITR_API_Postman_Collection.json` in Postman
- Run "Login" request with: `test@example.com` / `test123`
- Token is auto-saved, test other endpoints!
